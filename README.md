# 💸 Projeto Cripto Moedas — React + Vite + TypeScript

Aplicação web para visualização de preços e variações de criptomoedas em tempo real. Desenvolvido com foco em performance, escalabilidade e experiência do usuário.

O objetivo é demonstrar minhas habilidades em desenvolvimento front-end moderno utilizando **React**, **Vite** e **TypeScript**, com foco em:

- Consumo de APIs externas com tratamento de dados assíncronos
- Componentização e reutilização de elementos visuais
- Estilização com **Tailwind CSS** para agilidade e responsividade
- Deploy automatizado via **GitHub Pages**

---

## 🛠 Tecnologias utilizadas

- [React](https://reactjs.org/)
- [Vite](https://vitejs.dev/)
- [TypeScript](https://www.typescriptlang.org/)
- [Tailwind CSS](https://tailwindcss.com/)
- [GitHub Pages](https://pages.github.com/)
- [ESLint](https://eslint.org/) + [Prettier](https://prettier.io/) para padronização de código

---

## 🚀 Funcionalidades principais

- **Tabela de Criptomoedas**: exibe nome, preço em USD e variação nas últimas 24h
- **Filtro de favoritos**: permite marcar e visualizar apenas moedas favoritas
- **Design responsivo**: adaptado para desktop e dispositivos móveis
- **Atualização dinâmica**: dados carregados via API com feedback visual
- **Deploy público**: disponível em [GitHub Pages](https://douglasilva07.github.io/projeto-cripto-moedas/)
